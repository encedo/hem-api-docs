:::danger DIAG firmware builds only
The endpoints in this section exist only in diagnostic firmware builds (`DIAG_MODE_ON`). Production
firmware answers `404` for all of them. They are unauthenticated and some are destructive.
:::

The individual endpoint pages are added in a later migration step (M4).
