:::danger DIAG firmware builds only
The endpoints in this section exist only in diagnostic firmware builds (`DIAG_MODE_ON`). Production
firmware answers `404` for all of them. They are **unauthenticated** (no `Authorization` header, no
access scope) and several of them are **destructive**. Never expose a DIAG build outside a test bench.
:::
