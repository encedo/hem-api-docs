## Import a public key

<Endpoint method="POST" path="/api/keymgmt/import" operationId="importKey" />

Import a public key and save it in the repository of keys.

#### Headers

| Name                                            | Type   | Description       |
| ----------------------------------------------- | ------ | ----------------- |
| Authorization<Req /> | String | Bearer JWT\_TOKEN |
| Content-Type<Req />  | String | application/json  |

#### Request Body

| Name                                       | Type   | Description                            |
| ------------------------------------------ | ------ | -------------------------------------- |
| `descr`                                    | String | Base64 encoded additional description  |
| `label`<Req />  | String | Label of a key                         |
| `mode`                                     | String | Key operation mode (for NIST ECC only) |
| `pubkey`<Req /> | String | Base64 encoded external public key     |
| `type`<Req />   | String | Type of key to create                  |

#### Possible `pubkey` values

| Type       | Description                  |
| ---------- | ---------------------------- |
| SECP256R1  | NIST P-256 ECC key           |
| SECP384R1  | NIST P-384 ECC key           |
| SECP521R1  | NIST P-521 ECC key           |
| SECP256K1  | SEC2-v2 ECC key              |
| CURVE25519 | CURVE25519 ECC ECDH only key |
| CURVE448   | CURVE4ECC ECDH only key      |
| ED25519    | ED25519 ECC EdDSA only key   |
| ED448      | ED448 ECC EdDSA only key     |
| MLKEM512   | ML-KEM-512 key               |
| MLKEM768   | ML-KEM-768 key               |
| MLKEM1024  | ML-KEM-1024 key              |
| MLDSA44    | ML-DSA-44 key                |
| MLDSA65    | ML-DSA-65 key                |
| MLDSA87    | ML-DSA-87 key                |

#### Possible `type` values

| Value | Description |
|---|---|
| SECP256R1 | NIST P-256 ECC key |
| SECP384R1 | NIST P-384 ECC key |
| SECP521R1 | NIST P-521 ECC key |
| SECP256K1 | SEC2-v2 ECC key |
| CURVE25519 | CURVE25519 ECC ECDH only key |
| CURVE448 | CURVE4ECC ECDH only key |
| ED25519 | ED25519 ECC EdDSA only key |
| ED448 | ED448 ECC EdDSA only key |
| MLKEM512 | ML-KEM-512 key |
| MLKEM768 | ML-KEM-768 key |
| MLKEM1024 | ML-KEM-1024 key |
| MLDSA44 | ML-DSA-44 key |
| MLDSA65 | ML-DSA-65 key |
| MLDSA87 | ML-DSA-87 key |

#### Possible `mode` values (NIST ECC keys only)

| Value | Description |
|---|---|
| ECDH | Limit usage to ECDH only. |
| ECDH,ExDSA | Allow both ECDH and ECDH mode. |
| ExDSA | Limit usage to ExDSA only. |

#### Response data for successful operation

| Name | Type | Description |
|---|---|---|
| `kid` | String | Key ID, 32-character hex string |
