---
title: "Authentication"
description: "Those endpoints allow to authenticate based by External Authenticator."
---

:::info
These two endpoints are wide open and do not need any authorization data.
:::

#### Phase 1 - challenge

## Get a challenge

<Endpoint method="POST" path="/api/auth/ext/request" operationId="postAuthExtRequest" />

Get an authentication request data to challenge the external authenticator.

#### Headers

| Name                                           | Type   | Description      |
| ---------------------------------------------- | ------ | ---------------- |
| Content-Type<Req /> | String | application/json |

#### Request Body

| Name                                      | Type   | Description                     |
| ----------------------------------------- | ------ | ------------------------------- |
| `epk`<Req />   | String | Broker ephemeral public key     |
| `scope`<Req /> | String | Requested access scope          |
| `ctx` | String | Optional context — copied into the request JWT. |
| `note` | String | Optional human-readable note — copied into the request JWT. |

#### Phase 2 - response

## Post authentication data

<Endpoint method="POST" path="/api/auth/ext/token" operationId="postAuthExtToken" />

Post authentication data signed by an external authenticator.

#### Headers

| Name                                           | Type   | Description      |
| ---------------------------------------------- | ------ | ---------------- |
| Content-Type<Req /> | String | application/json |

#### Request Body

| Name                                          | Type   | Description                                       |
| --------------------------------------------- | ------ | ------------------------------------------------- |
| `authreply`<Req /> | String | Authentication data to be validated by the device |
